      WebView

      The component, its props and its ref.

      WebView

      What WebView carries besides the component: WebView.android and defaultNavigationRules.

      WebViewProps

      The WebView's props.

      CodedError

      What a ref method or a bridge call rejects with: an Error whose code says why.

      ErrorCode

      Why a ref method or a bridge call rejected. Each code means the same on every method that rejects with it.

      WebViewRef

      A WebView's ref.

      WebViewRefObject

      What createWebViewRef() returns: a ref that outlives the WebViews mounted with it.

      WebViewSource

      What the WebView loads: a URL, or an HTML string.

      createWebViewRef

      A ref to pass as a WebView's ref, made outside React (a module, a store) so code outside React can use it.

      WebView

      A WebView whose native side decides navigations and owns the navigation state: see WebViewProps and WebViewRef.

      Navigation

      The navigation state, and the rules that decide what each navigation does.

      NavigationAction

      What happens to a navigation.

      NavigationEvent

      A navigation decision, for onNavigation.

      NavigationRequest

      A navigation an ask rule puts to onNavigationRequest, or an external one to onOpenExternal.

      NavigationRule

      One navigation rule. Every field it sets must match; for a list, one matching entry is enough. A field left out matches anything; a flag set to false matches only the requests without it.

      NavigationState

      A WebView's navigation state, as native reports it: from useWebViewState and onNavigationStateChange.

      useWebViewState

      The navigation state of the WebView mounted with ref (a useRef, createRef or createWebViewRef one); re-renders on every change, and follows a remount.

      Events

      What onError, onProcessGone and onFullscreenChange receive.

      FullscreenChangeEvent

      A fullscreen change, for onFullscreenChange.

      LoadErrorEvent

      A main-frame error, for onError.

      ProcessGoneEvent

      The renderer process died, for onProcessGone.

      Bridge

      Calls and events between React Native and the page's window.nativeBridge.

      Bridge

      A promise-based RPC channel to window.nativeBridge in the page.

      BridgeEventMap

      The events either side may emit, for createBridge<Methods, Events>.

      BridgeHandler

      Answers a bridge call: the return value (a promise is awaited) is the result.

      BridgeMethodMap

      The methods either side may call, for createBridge<Methods>.

      BridgeOptions

      The options of createBridge.

      BridgeSender

      Who sent a call or event: the page's origin as location.origin writes it (https://example.com:8443), checked by native code, not taken from the page.

      createBridge

      Creates a promise-based RPC channel to window.nativeBridge in the pages of allowedOrigins, for one WebView's bridge prop.

      Scripts

      Scripts for injectedScripts, which run at document start.

      InjectedScript

      Runs at document start, before any page script and before the DOM is parsed.

      reactNativeWebViewMessages

      react-native-webview's messaging, for injectedScripts, carried by the bridge event rnw.

      Page requests

      File pickers, permission prompts and downloads the page starts.

      Download

      A finished download.

      DownloadFailure

      A download that could not be saved; kind says why:

      • network: connecting or reading the response failed, or a redirect was refused.
      • http: the response had an error status (Android only: iOS saves what the server sent).
      • data: the content: a bad data: or blob: URL, the page not reading its blob, an unsupported scheme, or a file above 100 MB.
      DownloadResult

      What onDownload gets.

      FileRequest

      An <input type="file">.

      PermissionRequest

      A page's permission request, for onPermissionRequest.

      PermissionResource

      A device resource a page can ask for.

      Native hooks

      Turning native hooks on with useExtensions, and what they send to onHookEvent.

      HookEvent

      An event a native hook sent with emit or ask.

      HookExtension

      A native hook's JS side, for useExtensions: its key, its hookOptions value, and what takes its events.

      useExtensions

      The hookOptions and onHookEvent props that turn on the hooks of extensions, to spread onto the WebView. Make one call per WebView, with every extension in its list: a second result spread onto the same WebView replaces the first one's onHookEvent, and the first one's asks then answer null.

      Platform settings

      WebKit and Android WebView properties, set by name through the ios and android props.

      AndroidConstants

      The WebSettings, WebView, WebSettingsCompat and WebViewCompat constants: settings: { cacheMode: AndroidConstants.WebSettings.LOAD_NO_CACHE }.

      IOSConstants

      WebKit's and UIScrollView's enums and option sets by raw value, for the iOS keys that take one: configuration: { dataDetectorTypes: IOSConstants.DataDetectorTypes.link }.

      AndroidSettingKeys

      The Android settings keys by root: the one-argument WebSettings, WebView and CookieManager setters, then WebSettingsCompat's and WebViewCompat's statics, then the scroll setters WebView inherits from View.

      AndroidSettings

      Android settings by setter name without set, applied by reflection, so any public setter works, including ones a newer SDK or androidx.webkit adds (under a root's other).

      CGPoint

      An iOS struct the settings channel carries as an object.

      CGRect

      An iOS struct the settings channel carries as an object.

      CGSize

      An iOS struct the settings channel carries as an object.

      IOSSettingKeys

      The iOS settings keys by root: the writable WebKit and UIScrollView properties the settings channel can carry, from the SDK headers.

      IOSSettings

      WebKit settings by Objective-C property name, set with Key-Value Coding, so any public property works, including ones this package has never heard of (under a root's other).

      SettingsRoot

      A settings root: its generated keys (IOSSettingKeys, AndroidSettingKeys, from the SDK headers), so a misspelled key fails to compile, and other for the keys they lack.

      SettingValue

      What a platform setting can take: what its property or setter accepts. An object is one of the iOS structs.

      UIEdgeInsets

      An iOS struct the settings channel carries as an object.
