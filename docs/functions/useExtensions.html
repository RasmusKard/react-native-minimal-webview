    Function useExtensions

    • useExtensions(
          extensions: readonly (false | HookExtension | null | undefined)[],
          props?: Pick<WebViewProps, "hookOptions" | "onHookEvent">,
      ): Required<Pick<WebViewProps, "hookOptions" | "onHookEvent">>

      The hookOptions and onHookEvent props that turn on the hooks of extensions, to spread onto the WebView.

      Make one call per WebView, with every extension in its list: a second result spread onto the same WebView replaces the first one's props, so the first one's hooks are off.

      hookOptions has each extension's options under its key, on top of props.hookOptions: an extension wins over a key of yours, and a later extension over an earlier one with the same key, which warns in development. Each event goes to the onEvent of the extension whose key its name starts with ('<key>.'; the longest key, when several do), and to props.onHookEvent when there is none or that extension has no onEvent. The handler's return value answers an ask.

      A false, null or undefined entry is left out, so on && extension(…) switches one on and off: its key leaves hookOptions. The result is the same object while the options are the same JSON, so a render with new handlers sends native nothing; the latest handlers always take the events.

      Parameters

      • extensions: readonly (false | HookExtension | null | undefined)[]
      • props: Pick<WebViewProps, "hookOptions" | "onHookEvent"> = {}
