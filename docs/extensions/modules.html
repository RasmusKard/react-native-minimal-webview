      @react-native-minimal-webview/extensions

      Extensions

      One function per extension, whose result goes into the core's extensions prop.

      androidLayerType

      Sets the WebView's layer type, and keeps it on the WebView that replaces one whose renderer crashed: react-native-webview's androidLayerType. Switched off, the layer type is 'none' again. Null on iOS.

      basicAuthCredential

      Answers HTTP auth challenges with credential, on every host: react-native-webview's basicAuthCredential.

      dialogs

      Answers the page's alert, confirm and prompt with onDialog instead of the native dialogs; the page waits for the answer. Not in react-native-webview, whose dialogs are native.

      hideKeyboardAccessoryView

      Hides the bar above the keyboard (previous, next, done) for the page's inputs: react-native-webview's hideKeyboardAccessoryView. Null on Android.

      menuItems

      The text selection menu: react-native-webview's menuItems, suppressMenuItems and onCustomMenuSelection. items replace the system's items, onSelect gets the one chosen, and on iOS suppress hides system items. Null when neither is set on this platform (suppress alone on Android).

      nestedScrollEnabled

      Keeps a swipe that starts on the page for the page, inside a scrolling parent such as a ScrollView: react-native-webview's nestedScrollEnabled. Null on iOS.

      onScroll

      Calls handler on each change of the scroll offset, with no throttling: react-native-webview's onScroll.

      Values

      What the functions take.

      AndroidLayerType

      A layer type of Android's View.setLayerType, for androidLayerType.

      BasicAuthCredential

      A user name and password, for basicAuthCredential.

      MenuItem

      An item of the text selection menu, for menuItems.

      SuppressMenuItem

      A system item of the text selection menu, by react-native-webview's name, for menuItems.

      Events

      What the handlers receive.

      CustomMenuSelectionEvent

      An item chosen from the text selection menu, for menuItems.

      Dialog

      A page's alert, confirm or prompt, for dialogs.

      ScrollEvent

      A scroll, for onScroll: react-native-webview's event, in points (iOS) or dp (Android).
