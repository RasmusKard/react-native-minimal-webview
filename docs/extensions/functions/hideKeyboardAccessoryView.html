    Function hideKeyboardAccessoryView

    • hideKeyboardAccessoryView(): HookExtension | null

      Hides the bar above the keyboard (previous, next, done) for the page's inputs: react-native-webview's hideKeyboardAccessoryView. Null on Android.

      It changes a private WebKit view, as react-native-webview does, so a WebKit update can stop it working.
