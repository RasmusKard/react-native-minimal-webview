NavigationRequest¶

NavigationRequest = object

A navigation an ask rule puts to onNavigationRequest, or an external one to onOpenExternal.

Properties¶

mainFrame¶

mainFrame: boolean

Whether it's the main frame's, not an iframe's.

newWindow¶

newWindow: boolean

Whether it's a new-window navigation (NavigationRule.newWindow).

url¶

url: string

The URL it goes to.

userInitiated¶

userInitiated: boolean

Whether a user gesture started it (NavigationRule.userInitiated).
