    outcome

    outcome: "finished" | "failed" | "cancelled" | null

    How the last main-frame load ended; null while one is loading, and before the first.

    • failed: a network or SSL error, or a renderer crash, cut it off.
    • cancelled: it never showed a page (a stop before the response, a download, a 204, a redirect the rules blocked, a load a newer one replaced); a stop after the page arrived is cancelled on iOS but finished on Android, and a 204 is finished on iOS 17.

    An HTTP error status (404) is finished: the site's page shows, and onError gets an http error. On Android with a WebView older than 146, a load that never commits changes nothing here.

    pendingUrl

    pendingUrl: string | null

    A main-frame load in progress, which may still fail or be blocked.

    Iframes never change it. Always null on Android with a WebView older than 146.

    progress: number

    From 0 to 1.

    url

    url: string

    The page on screen: changes on commit and same-document navigation (pushState, replaceState, hash), and stays the old page while a load is in progress.

    After a failed load, the failed URL. Iframes never change it.
