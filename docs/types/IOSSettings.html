    Type Alias IOSSettings

    WebKit settings by Objective-C property name, set with Key-Value Coding, so any public property works, including ones this package has never heard of (under a root's other).

    The keys the SDK headers list autocomplete, with their @since. A value must fit the property's type: enums and option sets by raw value (from IOSConstants), structs as objects, a UIColor as #rrggbb or #rrggbbaa, an NSURL as a string, websiteDataStore as 'default' or 'nonPersistent'.

    A key that doesn't fit, or a private (_) one, is skipped with a warning; nothing here can crash the app. A root's default keys are the package's, and yours go over them. Read one back with the ref's get.

    Example

    <WebView
      source={{ uri: 'https://example.com' }}
      ios={{
        configuration: { dataDetectorTypes: IOSConstants.DataDetectorTypes.link },
        scrollView: { bounces: false, contentInset: { top: 0, left: 0, bottom: 80, right: 0 } },
      }}
    />

    configuration?: SettingsRoot<

    WKWebViewConfiguration: read once, when the WKWebView is created; a change recreates the WebView (the page reloads and the navigation state starts over).

    The default lets a <video playsinline> play inline.

    The WKWebView, live.

    customUserAgent: null is WebKit's default user agent, with applicationNameForUserAgent appended.
