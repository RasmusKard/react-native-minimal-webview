    ErrorCode:
        | "timeout"
        | "not_found"
        | "handler_error"
        | "script_error"
        | "native_error"
        | "navigated"
        | "unavailable"

    Why a ref method or a bridge call rejected. Each code means the same on every method that rejects with it.

    • timeout: a bridge call got no answer in time.
    • not_found: nothing by that name answers: no bridge handler for the method, no attached hook name handling method, or no such root, key, method or selector (on this OS or WebView version too), or a malformed path.
    • handler_error: a bridge handler threw or rejected (the message is its error's), or the page sent a code not listed here.
    • script_error: evaluate's script threw, rejected or didn't parse.
    • native_error: the platform refused or failed the call: a member the core owns or a private one, wrong arguments, a completion handler call can't await, a native exception or NSError, or a result JSON can't carry (NaN).
    • navigated: the page or the WebView went away while the call was pending (a navigation, a crash, an unmount), so it may have run: retry only what is safe to repeat.
    • unavailable: the call didn't run: the WebView is gone or not mounted yet, is being rebuilt after its renderer died (Android), or lacks the feature (evaluate on an Android System WebView older than 83, the bridge older than 101, a compat method this WebView doesn't support).

    A programming error, such as an argument of the wrong type, can reject with a plain TypeError instead.
